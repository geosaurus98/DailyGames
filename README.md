# Daily Games Hub

A single self-contained page (`index.html`) for tracking the daily puzzle games I play.
Open it in a browser, or host it anywhere static (GitHub Pages works).

- Cards link out to each game in a new tab. Tick a game off when you've done it.
- Set each game to Daily, Bonus or Hidden in **Customise** mode.
- Streaks count days where every Daily game was done. Days reset at midnight NZ time.
- Data stays in your browser (localStorage). Use **Export** and **Import** to back it up or move devices.

To add or remove games, edit the `GAMES` array in `index.html`. The comment block at the top of the file explains how.
